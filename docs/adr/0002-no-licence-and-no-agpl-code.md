# No licence for now, so no AGPL code in the app

The repo stays all rights reserved so that a paid, buy-once version remains possible. That rules out porting AGPL code into the app: the Lichess puzzle-theme tagger is rewritten, not copied, and Maia-3 (AGPL) could only ever run as a separate process. Maia-1 is used for now. Lichess's sounds (AGPL) are still in the app and must be replaced before any paid version. Lichess database positions are public domain (CC0) and may be used as content.
